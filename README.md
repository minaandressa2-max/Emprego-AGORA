# 🚀 Emprego Agora (Matchmaker AI)

O **Emprego Agora** é uma ferramenta inteligente desenvolvida para ajudar profissionais a analisarem a compatibilidade de seus perfis com vagas de emprego e gerarem currículos otimizados para sistemas ATS (Applicant Tracking Systems), totalmente **sem a necessidade de cadastro ou login**.

🔗 **URL da Aplicação:** [https://matchmaker-ai-44.lovable.app/](https://matchmaker-ai-44.lovable.app/)  
📁 **Repositório:** [https://github.com/minaandressa2-max/Emprego-AGORA](https://github.com/minaandressa2-max/Emprego-AGORA)

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React, TypeScript, Tailwind CSS
- **Build Tool:** Vite
- **Roteamento:** TanStack Router
- **Backend & Banco de Dados:** Supabase

---

## 📌 Principais Funcionalidades

- **Perfil Persistente no Navegador:** Preencha seus dados de experiência, formação e habilidades uma única vez; tudo fica salvo no armazenamento local (*localStorage*).
- **Análise de Aderência & Match:** Cole a descrição da vaga desejada para obter a porcentagem de compatibilidade, critérios avaliados, pontos fortes, lacunas de perfil e palavras-chave faltantes.
- **Gerador de Currículo ATS:** Gere versões reescritas do seu currículo integrando as palavras-chave da vaga para aprovação em leitores automáticos.
- **Exportação Fácil:** Pré-visualize a formatação, faça download em formato texto ou salve em PDF direto pela impressão do navegador.
